# VBOX Test Suite File Renamer

A Windows-friendly Python desktop application for safely correcting the serial prefix of VBOX Test Suite filenames and adding missing road type and KM distance text from Excel.

The app is designed for files such as:

```text
4.0_Smooth_Highway_KHALGHAT_TOLL_PLAZA_TO_JULWANIYA_MP_48.6_KM_part_001.vbo
```

If that matched file is number `3` in the generated order, the renamed file becomes:

```text
3_Smooth_Highway_KHALGHAT_TOLL_PLAZA_TO_JULWANIYA_MP_48.6_KM_part_001.vbo
```

The serial prefix is generated from matched file order, starting at `1` and continuing to the last matched file. Files are ordered by their matched Excel start/end route first, then by part number. If the filename has no road type or `KM` distance, the app adds them from the matched Excel row.

It also supports files that do not have a serial prefix yet, for example:

```text
Akshay Honda, Dhule__to__Arvi, Maharashtra__(part_1_3).vbo
```

If that matched file is number `8` in the matched-file order, the app adds the prefix:

```text
8_City_Road_Akshay Honda, Dhule__to__Arvi, Maharashtra__(part_1_3).vbo
```

If that Excel row also has distance `24`, the renamed file becomes:

```text
8_City_Road_Akshay Honda, Dhule__to__Arvi, Maharashtra__24_KM__(part_1_3).vbo
```

## Features

- Safe preview before rename
- Shows the generated file-order Serial Number in preview/export/log files
- Adds missing road type such as `City_Road` from the matched Excel row
- Adds missing distance text such as `24_KM` from the matched Excel row
- Never overwrites existing files
- Detects duplicate target names and conflicts
- Writes `rename_log.json` and `rename_log.xlsx` before renaming, then updates them after rename
- Undo rename using the JSON log
- Case-insensitive matching
- Ignores spaces, underscores, hyphens, dots, commas, and minor formatting differences
- Handles small spelling differences such as `Julwaniya/Julwania`, `Nashik/Nasik`, `Tol/Toll`, and missing letters
- Supports common abbreviations such as `Madhya Pradesh` and `MP`
- Supports `.vbo`, `.vbox`, `.vts`, and custom extensions
- Optional subfolder processing
- Search/filter in the preview table
- Export preview to Excel
- Drag and drop folder or Excel file onto the window
- Manual Excel column mapping from dropdowns

## Attached Workbook Support

The included route profile workbook has one sheet with two tables:

- Upper section: A to B
- Bottom section: B to A

The app detects both sections automatically and skips `Total` rows. Rename serials are generated by matched file order:

- Files matched to A to B rows first
- Files matched to B to A rows next
- Multiple files for the same start/end route continue the sequence by part number

For the attached workbook, this creates 24 route rows. The app prefers `TOTAL DISTANCE OF EACH SECTION` for matching distance because that is the value used in filenames such as `48.6_KM`.

If you need a different route order, reorder the route rows in Excel before loading the preview.

## Supported Excel Columns

The app auto-detects these column names and similar variants:

- Serial, optional: `Serial`, `Sr No`, `Sr. No`, `Sequence`, `Serial No`, `Serial Number`
- Start point: `Start Point`, `Start`, `From`, `Origin`, `Landmark (From)`
- End point: `End Point`, `End`, `To`, `Destination`, `Landmark (To)`
- Road type: `Road Type`, `Type`, `Surface Type`, `Type of Road`
- Distance: `TOTAL DISTANCE OF EACH SECTION`, `Distance / km`, `Distance (km)`, `Distance Covered (km)`, `KM`, `Length`

If your workbook uses different names, open the `Map Columns` tab and choose columns manually.

## Matching Tolerance

Matching is case-insensitive and fuzzy. It can match filenames even when the Excel text is not exactly the same, for example:

```text
Excel: Khalghat Toll Plaza -> Julwania, Madhya Pradesh
File:  KHALGAT_TOL_PLAZA_TO_JULVANIYA_M_P
```

The app still stays safe: if two Excel rows look equally possible, the row is marked `DUPLICATE`/ambiguous in preview and is not renamed automatically.

## Installation

Install Python 3.8 or newer, then run:

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Usage

1. Click `Select Folder` and choose the folder containing VBOX files.
2. Click `Select Excel` and choose the route profile workbook.
3. Check the `Map Columns` tab. Adjust dropdowns if required.
4. Set serial format in `Settings`:
   - `1`
   - `1.0`
   - `001`
5. Click `Load Preview`.
6. Review every row in the preview table.
7. Optionally click `Export Preview`.
8. Click `Rename Files` only after confirming the preview is correct.

## Preview Status

- `MATCHED`: safe to rename
- `UNCHANGED`: file already has the correct serial prefix
- `NOT_FOUND`: no reliable Excel match
- `DUPLICATE`: multiple files or Excel rows would create ambiguity
- `CONFLICT`: target filename already exists

Only `MATCHED` files are renamed.

## Undo

Open the same folder in the app and click `Undo Last Rename` from the `Settings` tab.

Undo uses:

```text
rename_log.json
```

The app will not undo over an existing original filename.

## Build EXE Later

Install PyInstaller:

```bash
pip install pyinstaller
```

Build:

```bash
pyinstaller --onefile --windowed --name VBOXRenamer main.py
```

The executable will be created in `dist`.

## Safety Notes

- The app performs a dry-run preview first.
- It updates the serial prefix by matched file order and only adds road type/KM distance when missing.
- It never overwrites existing files.
- Unmatched, duplicate, conflict, and already-correct files are not renamed.
- Logs are written locally in the selected VBOX folder.
